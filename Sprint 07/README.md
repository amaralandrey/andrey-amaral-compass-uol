
## Desafio

Nesta sprint, o desafio teve como objetivo a ingestão de dados da API do TMDB em um bucket S3 da AWS, utilizando uma função AWS Lambda.  
A finalidade do desafio era complementar os dados fornecidos na sprint anterior para responder a questão definida para o desafio final. Contudo, a questão que defini é relacionada a bilheteria dos filmes, dado que não é disponibilizado pela API do TMDB. Em razão disso, para cumprir o desafio, decidi buscar os 100 filmes de crime mais populares no TMDB e para as próximas etapas buscarei utilizar outro API.  
O desafio completo está detalhado no diretório.
