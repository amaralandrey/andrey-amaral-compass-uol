
# Desafio

Nesta sprint, o desafio teve como objetivo a aplicação das formas normais a um esquema de banco de dados e a construção de um modelo dimensional a partir do modelo normalizado. 

# Exercícios

Foram feitos 16 exercícios de SQL com a sintaxe SQLITE na plataforma da Udemy, divididos em dois temas, biblioteca e loja. As respostas usadas na plataforma estão em arquivos TXT e SQLITE na pasta exercícios.
