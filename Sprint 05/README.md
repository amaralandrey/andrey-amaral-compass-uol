
## Desafio

O objetivo do desafio era a prática de consultas SQL no ambiente da AWS.  
Quanto ao problema a ser resolvido, era a realização de vários tipos de consultas em um objeto no S3.  
Ao todo, incluindo a entrega, o desafio tinha seis etapas, as quais estão descritas e documentadas no diretório Desafio.  

## Evidências

- Evidência 01: tela de finalização das etapas do Cloud Quest.  
- Evidência 02: medalha de conclusão de todas as etapas do Cloud Quest. 
- Evidência 03: tela de configuração do console AWS, com a inicialização de uma instância EC2.
- Evidência 04: tela de criação do bucket S3 para o desafio.
- Evidência 05: resultado da consulta-1 no console da AWS sem a inconsistência que está no json baixado do console.

## Certificados

Nesta sprint fizemos o curso de preparação para o exame AWS Certified Cloud Practitioner (CLF-C02), certificado de conclusão na pasta Certificados, e o AWS Cloud Quest: Cloud Practitioner, o badge de conclusão do jogo está na pasta Evidencias.

## Dificuldades encontradas na Sprint

Tive bastante dificuldade de utilizar Python para realizar o desafio, pois não consegui fazer a validação com as credenciais da AWS, por isso decidi fazer o desafio todo no console do S3.  
Outra dificuldade foi a utilização das funções de data do S3 Select, pois elas são muito rígidas quanto aos dados que aceita tratar, por isso não consegui realizar a parte do desafio que pedia a utilização dessas funções.
